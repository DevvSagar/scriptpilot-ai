## 📖 Overview

ScriptPilot AI is an AI-powered platform that helps filmmakers, producers, and screenwriters analyze movie scripts in seconds.

Instead of manually reading hundreds of pages, users can upload a screenplay, ask questions, generate summaries, identify characters, discover locations, and automate production planning using Google's Gemini AI.

---

## ✨ Features

### MVP

- Upload screenplay PDFs
- AI-powered script summarization
- Ask questions about uploaded scripts
- Store uploaded scripts
- Chat with your screenplay

### Planned

- Character extraction
- Scene breakdown
- Location detection
- Shooting schedule generation
- Production planning assistant
- Multi-agent workflow
